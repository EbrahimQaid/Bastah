# دكاني - Dukkani 🛍️

منصة التجارة الإلكترونية الذكية للمتاجر والمشاريع الصغيرة والمتوسطة، مدعومة بهوية محفظة جيب الإلكترونية ونظام إدارة متكامل.

## الهيكلية المعمارية (MVC Architecture)

تم بناء التطبيق وفق نمط **Model-View-Controller (MVC)** المتين لضمان سهولة الصيانة وقابلية التوسع:

- **Models (`server/models/`)**:
  - `storeModel.js`: إدارة بيانات المتاجر، الإعدادات، والهوية البصرية.
  - `productModel.js`: إدارة المنتجات، التصنيفات، المخزون، والأسعار.
  - `orderModel.js`: إدارة الطلبات وحالاتها والعمليات الحسابية والخصومات.
  - `categoryModel.js`: تصنيفات المنتجات والأقسام.
  - `userModel.js`: إدارة التجار والحسابات والصلاحيات.

- **Controllers (`server/controllers/`)**:
  - `storeController.js`: معالجة طلبات واجهة المتجر للعملاء والطلبات الجديدة.
  - `dashboardController.js`: معالجة عمليات لوحة تحكم التاجر والإحصائيات.
  - `authController.js`: المصادقة، تسجيل الدخول، وإنشاء المتاجر الجديدة.

- **Routes (`server/routes/`)**:
  - `storeRoutes.js`: مسارات واجهة المتجر العامة `/api/store`.
  - `dashboardRoutes.js`: مسارات لوحة التحكم المحمية `/api/dashboard`.
  - `authRoutes.js`: مسارات المصادقة `/api/auth`.

- **Views (`src/`)**:
  - واجهات React العصرية المتجاوبة مع دعم كامل للغة العربية (RTL) والأجهزة الذكية.

## تشغيل المشروع محلياً

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير الشامل (Frontend + Backend)
npm run dev
```

## متغيرات البيئة (Environment Variables)

- `DATABASE_URL`: رابط اتصال قاعدة بيانات PostgreSQL (يدعم العمل بوضع الذاكرة المؤقتة في بيئة المعاينة).
- `JWT_SECRET`: المفتاح السري لتشفير الـ Tokens.
- `PORT`: المنفذ المخصص للتشغيل (الافتراضي 3000).
- `STORE_ID`: معرّف المتجر النشط الافتراضي.
- `CORS_ORIGIN`: قائمة النطاقات المسموح بها مفصولة بفواصل.

## النشر (Deployment)

التطبيق مهيأ بالكامل للنشر الفوري على منصة **Vercel** أو أي بيئة استضافة Node.js / Docker.
تم تضمين إعدادات `vercel.json` لتوجيه طلبات الواجهة والـ API بسلاسة.
