# بَسطة - تطبيق المتجر

تطبيق Flutter للعملاء فقط. الداشبورد وإدارته يظلان في تطبيق الويب الرئيسي.

## التشغيل

من داخل هذا المجلد:

```powershell
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:3001/api
```

`10.0.2.2` مخصص لمحاكي Android. على iOS Simulator استخدم `http://localhost:3001/api`، وعلى جهاز حقيقي استخدم عنوان IP لجهاز التطوير داخل الشبكة.

## الوظائف الحالية

- الرئيسية والبحث والتصنيفات والمنتجات.
- إضافة المنتجات للسلة وتعديل الكميات.
- نموذج بيانات التوصيل وإرسال الطلب إلى `/api/store/orders`.
- يدعم تشغيل التطبيق بالعربية واتجاه RTL.

عند النشر، مرّر عنوان الخادم الحقيقي عبر `API_BASE_URL` بدل العنوان المحلي.
